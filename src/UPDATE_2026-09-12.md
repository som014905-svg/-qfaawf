# Update — VM/Chain recovery

Implemented:
- Hercules v3 VM/bytecode structural detection and conservative opcode-handler lifting.
- MoonSec VM conservative opcode-handler lifting after string-table recovery.
- MoonVeil conservative opcode-handler lifting.
- IronBrew2/IB2 conservative opcode-handler lifting.
- LuaObfuscator Chaotic Evil conservative opcode-by-opcode lifting when the dispatcher and bytecode layout are statically provable.
- Loader chain now follows embedded Lua payloads executed through `loadstring(payload)` in addition to HTTP(S) URLs, covering wrappers such as luast -> WeAreDevs.
- Unknown VM opcodes are preserved as annotated comments instead of guessed semantics.

Safety/integrity:
- No Lua/Roblox code is executed during these passes.
- VM lifting is intentionally conservative; if the handler semantics or bytecode layout cannot be proven, the original VM is retained.

## Luast v1.x sample update — 2026-09-12

Added a dedicated `LuastDeobfuscator` profile for the uploaded Luast v1.0.1 sample shape:
- Detects the `generated by luast v...` banner plus nested numeric object-table lookups.
- Recovers immutable scalar values from patterns such as `T[128] = { ... }` and `T[128][N]` without executing Lua.
- Handles local aliases such as `local am2 = T[128]` inside their lexical block.
- Tracks per-slot writes and refuses substitutions for mutated slots (for example anti-tamper/random slots).
- Re-applies table recovery after safe structural rewrites.
- Runs conservative numeric decision-tree recovery only when full static syntax validation passes.
- Rejects aggressive generic rewrites when they make the recovered Luau invalid.

Validation against the uploaded sample:
- Input: 719,874 bytes.
- Dedicated Luast pipeline output: 710,307 bytes.
- Static syntax validator: 0 errors.
- Recovered immutable table lookups in the first two passes: 3,248 total (direct + local-alias).
- Numeric decision-tree recovery was accepted only for syntax-valid rewrites.

The repository still never executes the target Lua/Roblox script during deobfuscation.
